Website that is a launcher to other websites, including providing authentication for accessing local running websites with authentication and https from remote.

## Cybersecurity

Number one priority, particularly about malicious devices on same network getting access to this or served apps. When doing a change that might affect it always trigger a subagent for cybersecurity review and act accordingly also based on your own judgement. Concerns that remain always get raised. Debatable decision surfaced simply to user (assuming programming knowledge but not necessarily deep cybersecurity skills).
- if you are claude, subagent is Opus latest w/ medium effort
- if you are codex, subagent is Sol latest w/ high effort
- otherwise ask

## Speed

This is a launcher that might even be home page. Fast, uncomplicated loading is very important. when working on UI always think about this. Dozens of milliseconds count. Things like favicons should be cached/lazy loaded. Website code should be minimal. No dependencies needed.

## UI

Must look nice on mobile (optimize for vertical space), tablet ~ 11" (both horizontal and vertical), laptop 13,14,15,16", and 27,32".
